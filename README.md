# push-kaggle

Kaggle publishing skill — dataset creation/versioning, notebook push, credentials setup, and Kaggle-specific limitations.

## What it does

- Dataset publishing (creation + versioning)
- Notebook push (kaggle kernels push)
- Credentials setup (kaggle.json / env vars)
- Kaggle limitations (no Streamlit hosting)

## Install

```bash
npx skills add phycomp/push-kaggle@push-kaggle -g -y
```

## Usage

Trigger phrases: "kaggle", "kaggle dataset", "kaggle publish", "kaggle notebook".
